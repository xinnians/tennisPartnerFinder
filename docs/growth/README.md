## 從這裡接續

1. 讀 [目前進度](progress.md)，確認工作區、最近驗證與下一步。
2. 讀 [目標與執行計畫](plan-2026-09-09.md)，選擇尚未完成且依賴已具備的工作。

4. 開始、改變範圍、完成驗證和結束 session 時更新進度。新決策、阻礙和待觀察結果都需留下日期。
