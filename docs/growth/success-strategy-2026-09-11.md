# 球咖成功策略：先驗證局部重複成局

日期：2026-09-11。性質：多角度分析與建議，不是新功能、試點招募或部署授權。G01、G05–G08、G11–G12 的暫緩狀態不因本文件改變。

後續偏好更新：使用者希望降低主動約訪壓力，已完成[自然獲客起步計畫](inbound-launch-plan-2026-09-11.md)。以下主揪訪談／試點保留為策略選項，並非目前起步的必要條件；新計畫尚未實際發布或開始量測。

## 結論與前提

建議下一階段把資源重心轉到「一個球場群、固定時段、可相互配合的程度，讓非創辦人主揪持續補到缺額」。核心待驗證承諾是：**幫固定打球的主揪，省事地補到合適球友。** 球場指南作為獨立有用的入口，同時驗證是否帶來真正約球需求。

暫以小團隊、有限預算、優先建立持續使用為前提；使用者的營收目標、目前活躍數、實際成局數、可投入工時與可接觸主揪仍未知。若目標是內容事業或快速擴張，資源配置須重新選擇，不以本建議代替使用者決策。

最需要避免的資源風險，是工程與內容持續增加，卻沒有更接近「誰需要、為什麼再用、是否願意付費」的證據。

## 七個角度

| 角度 | 判斷與風險 | 建議行動 | 可推翻判斷的證據 |
| --- | --- | --- | --- |
| 使用者需求 | 無固定球友者痛點可能大，但每次從零組人難度高；已有固定局的主揪可提供較確定的機會 | 先訪談固定打球、偶爾缺 1–2 人且願意接納新球友的主揪；參加者先選已有基本對打能力、時間地點相容者 | 主揪很少缺人、排斥陌生人或既有群組總能即時補滿，表示切入點不成立 |
| 市場密度 | 每個地點、時段、程度與玩法交集都可能是一個很小的市場；全台總註冊無法代表某人今晚有球可打 | 選一個交通可接受的球場群與 1–2 個重疊時段，先集中招募與營運 | 集中後仍無法找到相容需求，須換時段／客群或定位，不能只加更多城市 |
| 場地供給 | 找人與找到可用場地是兩個問題；沒有場地可能讓表面媒合成功仍打不成 | 試點優先採主揪已自行確認可使用的場地，每局重新確認；記錄場地／天候取消 | 若多數失敗來自訂不到場，優先研究場地方合作或有固定使用時段的主揪，而非加配對算法 |
| 競爭與分發 | 用戶既有協調習慣是重要替代方案；地圖、程度篩選、聊天本身難形成區別 | 讓主揪自願在既有管道分享公開球局連結，球咖承接名額、狀態與局內協調；量跨工具總耗時 | 若多一道網站操作反而更慢，須簡化流程或改價值主張 |
| 首次體驗與信任 | 新人需要知道能不能打、何時確認、費用、場地及取消方式；完整檔案不等於球品認證 | 觀察 5 位目標參加者實際找局，先修最常造成放棄的單一問題，盡量用既有費用／備註欄位 | 有相容真實球局且資訊清楚仍不想參加，需查陌生人顧慮或需求強度 |
| 留存與營運 | 約到固定球友後轉站外可能是需求完成；也可能使平台失去再次服務機會 | 分別量初次媒合價值、主揪再用、再次打成及創辦人介入分鐘 | 少了創辦人逐場催促就停止，表示服務尚依賴人工，未證明可複製 |
| 商業與防守性 | 有人在用未必有付費需求；可信指南需要持續維護，固定主揪關係也需要營運 | 在省時／補缺價值被反覆證明後，測明確付費方案；累積可靠供給、維護品質與主揪合作 | 主揪持續使用但不願為任何額外價值付費，需另找付費方或承認公益／內容模式 |

主揪並非必然是最佳客群，而是適合用小成本先驗證的假設。新手需求若更強，可另測有明確主持與最低能力說明的練球局，但主持與教學是不同服務，不能預設一般主揪願意負擔。

## 競品給出的實際啟示

[Playtomic Community Match](https://playerhelp.playtomic.com/hc/en-gb/articles/19831629310481-Community-Match-Play-on-Any-Court-Anywhere) 允許在合作球館之外建局、分享、通知與聊天，並明示訂場／付款由主揪處理。這支持球咖可以先專注協調工具的產品路線，但不證明台北需求已成立，也不能宣稱球咖的模式獨有。

[Playtomic 杜拜 WhatsApp 群說明](https://playerhelp.playtomic.com/hc/en-gb/articles/19831691884561-Official-WhatsApp-groups-in-Dubai-to-organize-and-promote-Playtomic-public-matches) 記載按程度分群、分享公開球局連結。可以借鏡聊天工具作為分發管道；是否適合台灣 LINE 仍需試點。本輪未加入群組、讀取私人內容或代發訊息。

[Tennistry 開發者說明](https://apps.apple.com/tw/app/tennistry/id6757626581) 已主打依時間與程度自動配對、休閒與排位。因此「我們有配對功能」不足以成為有力差異；球咖應測能否在具體台北生活圈提供可靠機會與更省事的協調。沒有取得該產品本地供給或留存數據。

## 指南應如何繼續

61 篇指南是已完成的資產，可獨立幫助查場地者。下一階段建議保留查錯、重大異動與試點球場補強，把大範圍新增內容的優先度降下來。這是資源建議，沒有取消使用者既有補證要求。

分開追蹤兩種成果：

1. 內容價值：來源是否現行、使用者是否找到需要的入場資訊、是否重複查閱、錯誤回報如何處理。
2. 媒合價值：哪些指南帶來真實建局／加入意圖，之後是否 accepted、打成及再用。索引頁瀏覽、訂閱或 CTA 點擊都不是成局。

若出現穩定搜尋需求但幾乎沒有約球意圖，可能是內容／場地決策工具的機會。應獨立評估使用頻率、維護工時、合作收入與付費方，而非把內容流量當成媒合市場成立。自然搜尋曝光通常需要持續觀察，短期未轉換不能單獨否定指南；先用已接觸的目標使用者測需求相關性。

## 六週驗證提案

以下人數與門檻是可修改的管理假設，不是產業 benchmark、成長預測或已達成成果。尚未啟動招募／追蹤，日期待維護者安排。

| 階段 | 具體工作 | 決策證據 |
| --- | --- | --- |
| 第 1 週 | 訪談約 5 位主揪與 5 位參加者；回顧最近一次真實約球及失敗；找到 3–5 位有試用意願的主揪，依其可接觸性選場地群／時段 | 缺額頻率、原有補人方法、協調分鐘、場地確定性；至少取得實際下次使用承諾，而非只有稱讚 |
| 第 2 週 | 由主揪本人建立真實球局並分享；以約 20–30 位相容且自願的球友作招募規模假設，按真實名額分批邀入 | 球咖是否帶來原先補不到的人；每場需要創辦人介入多少；不承諾人人一定有局 |
| 第 3–4 週 | 觀察同批人第二次使用；逐步減少提醒；依最大流失原因只做一項修正 | 先找至少 2 位非創辦人自主重開並有再次打成回報；記錄是原班熟人還是新增關係 |
| 第 5–6 週 | 追蹤已有完整 28 天觀察窗的首次打成者與首次主揪；訪談持續使用／離開者 | 是否重複提供價值、人工成本是否下降；未滿觀察窗保留觀察中，必要時延長 |

每週可用 50% 時間做主揪／參加者接觸及成局跟進、30% 修已觀察的產品摩擦、20% 做量測和指南維護，作為起始配置。若只能投入極少工時，把主揪與場地群縮小，勿同時擴大多條產品線。

招募管道優先順序：現有球友介紹 → 願意介紹固定練習者的教練／主揪 → 經管理者同意的社群公開招募 → 與試點球場相關的指南。主張應描述具體場合與程度，避免泛稱「新平台歡迎註冊」。不爬取或匯入私人社群名單。

訪談三問：上一次想打卻沒打成發生了什麼？最近一次補人實際花了哪些步驟與時間？下一次有缺額，你願不願意自己用球咖開一次？先觀察行為，再問想要什麼功能。

## 最小計分板與決策規則

首要結果沿用既有計畫：每週主揪回報打成、且至少一位非主揪確認出席的真實球局數。這是自報代理指標；並列未取得確認的回報，不把未回報全部算成失敗。

| 指標 | 定義與用途 |
| --- | --- |
| 有效供給覆蓋 | 去重且完成載入的有效搜尋中，有至少一個符合條件且可加入機會的比例；錯誤另列，早期可用人工觀察樣本 |
| 補缺價值 | 每局 accepted／出席人數，以及主揪自報若沒球咖是否已有其他補人方式；這是增量價值線索，不能宣稱已證明因果 |
| 主揪自主重開 | 非創辦人不用逐場催促建立第二局的人數／符合觀察條件主揪數，另列第二局是否打成 |
| 28 天重複打成 | 首次打成後 28 天內再次打成且本人確認者／完整 28 天窗的首次打成者；主揪與參加者分開 |
| 總協調成本 | 主揪跨工具的主動操作分鐘，與創辦人每局介入分鐘分開記錄，量是否真的省事 |
| 取消／落空 | 缺人、場地、天候、程度不合、無回覆、臨時取消等固定類別；未知與無回報另列 |

可先用既有試點 Markdown 表與自願回報，不以先完成分析系統作為訪談前提。自動化漏斗另立最小 spec，以伺服器成功去重，不蒐集聊天、私人聯絡、精確 GPS；訪客歸因須有一致分母與明確限制。

決策順序：

- 沒有合適球局：先補相容供給與時段，首頁優化無法憑空造局。
- 有合適局但看不到／載入太慢：優先首屏、列表與速度；G05 可重新提出最小實驗。
- 看了不敢加入：查資訊、玩法、費用、程度與信任；優先用現有欄位改善。
- 願意加入但沒被確認：查主揪回應與通知鏈路，不能把 requested 當 accepted。
- 打成卻不再用：分辨需求已完成、沒有下一次缺額、協調沒省時或體驗差。
- 只靠創辦人催促能成：延長營運驗證或改客群，不擴城市；若當作人工服務經營，須計入完整人力成本。
- 重複成局且逐場人工介入下降：在相鄰球場群複製一次，再評估規模擴張。

小樣本以 2/5 等原始分子分母解讀，不宣稱統計顯著；雨天、供給變化、來源與熟人比例均保留。

## 商業路徑與暫緩事項

先確認誰得到反覆價值，再測誰付費。主揪管理進階方案、場地／教練合作、策劃活動或內容贊助是不同路線，尚未核可新增商業功能。若測付費，應說清楚提供的服務與價格，取得實際付費行為並觀察續用，不能把口頭「願意付」當營收。

可持續性的基本式是：每月收入減去平台變動成本、招募成本、內容維護與客服／營運人力成本。創辦人工時也要計價。純假設試算：100 位付費者 × NT$199／月 = NT$19,900 月營收，尚未扣成本，既不是需求預測也不是定價建議。先用這類算式釐清目標收入需要多少持續付費者。

現階段建議暫緩廣泛投廣告、多城市／多運動、原生 App、排行榜、泛社群、複雜 AI 媒合、無漏斗依據的大改版與純架構重整。若當前故障阻礙加入或損害資料安全，仍應優先修復。場地規則涉及營利／活動限制時，須於採用商業路線前另行查核，不能預設可收費營運。

目標差異：持續使用先看重複成局；小生意另需有付費與扣除人力後的利潤；可擴張平台還需要第二個生活圈可複製、獲客與維運成本可承受。前一階段成立不自動代表後一階段成立。
