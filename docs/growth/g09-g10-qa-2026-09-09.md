使用 repo Playwright production preview、實際 local Supabase、Fake Maps／平台端點 stub。桌面 1280px、手機 390×844；手機 PNG 含裝置像素比，不能把圖片寬度當 CSS viewport。透過 `view_image` 同回合開啟已核可稿與瀏覽器截圖比較。

| 面向 | 對照與結果 |
| --- | --- |

| 詳頁閱讀順序 | 桌面左資訊右操作與球局；手機標題 → 主操作 → 球局 → 租借／設施／交通／來源 |

| 錯誤與焦點 | 球局失敗時指南仍可讀；重試後焦點落在近期球局標題，依 generation 避免過期回應覆寫 |
| 首訪資源 | 索引無 JS；詳頁沒有 Maps、private repository 或 Push runtime 請求，主要文章在原始 HTML |
