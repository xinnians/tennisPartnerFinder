# G09／G10 QA 與發布接續

日期：2026-09-09。範圍：已核可的 G09 三座球場指南及 G10 逐局分享預覽。正式部署狀態以 `progress.md` 為準。

## 視覺與操作

使用 repo Playwright production preview、實際 local Supabase、Fake Maps／平台端點 stub。桌面 1280px、手機 390×844；手機 PNG 含裝置像素比，不能把圖片寬度當 CSS viewport。透過 `view_image` 同回合開啟已核可稿與瀏覽器截圖比較。

| 面向 | 對照與結果 |
| --- | --- |
| 索引結構 | 桌面三欄、手機一欄，各含名稱、行政區、短說明、指南連結；均無水平溢出 |
| 詳頁閱讀順序 | 桌面左資訊右操作與球局；手機標題 → 主操作 → 球局 → 租借／設施／交通／來源 |
| 主操作 | 黃綠「在這裡開球局」與深綠次要訂閱入口；沒有額外付費、訂場或新通知授權流程 |
| 視覺語彙 | 暖白底、白卡、墨綠文字、細邊框及 Noto Sans TC；使用既有 icon.svg，替代概念稿示意字標 |
| 卡片與觸控 | 主操作至少 48px；文字入口至少 44px。手機球局卡修訂為右側查看入口，減少三筆活動的高度 |
| 內容差異 | 移除「設計提案／示意球局」審閱標記；正式欄位依官方來源成稿。青年時間／費率保留待確認；真實 local fixture 活動多於概念稿的一筆 |
| 錯誤與焦點 | 球局失敗時指南仍可讀；重試後焦點落在近期球局標題，依 generation 避免過期回應覆寫 |
| 首訪資源 | 索引無 JS；詳頁沒有 Maps、private repository 或 Push runtime 請求，主要文章在原始 HTML |

瀏覽器截圖保存於 [g09-design/qa](g09-design/qa/)：index／guide／error 各桌面與手機。截圖內活動是 local 測試資料，不是正式站活動。

- 零 migration，沒有改 hosted DB、Edge Functions 或 cron；依 repo 規則略過本機 pgTAP，遠端 Supabase CI 仍照原工作流執行。

未提高原核可上限，所有數字為 bytes。以下是本機一般設定 build；正式環境 build 另列於發布結果。

| 項目 | Raw | Gzip | 上限 raw／gzip |
| --- | ---: | ---: | ---: |
| Main | 385,077 | 119,179 | 680,000／200,000 |
| Root 完整靜態依賴 | 660,061 | 193,004 | 700,000／205,000 |
