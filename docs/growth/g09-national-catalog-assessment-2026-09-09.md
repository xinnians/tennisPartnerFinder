# G09 指南擴充與全台球場資料：可行性評估

日期：2026-09-09。狀態：使用者詢問是否適合擴充，本文件是建議，尚未核可全量匯入、全台公開指南或跨縣市開局。既有 G09／G10 上線狀態不變。

## 結論與現況

建議擴充台北指南，同時規劃全台資料底稿；分開管理「收錄場地」「發布指南」「開放約球」。目前 `data/courts.json` 89 座（台北 61、新北 28），不代表雙北絕對完整清單或網球場地面數。正式完整指南 3 篇。15 張舊研究卡可當查核起點，不能直接視為現行租借指南。

G09 提供找場地／確認租借的使用理由，可能增加搜尋與回訪機會；是否轉換為約球及留存仍需觀察，不以頁數或目錄筆數代替成效。此次租借系統切換更正顯示維護能力應先於一次發布全部內容。

## 建議分階段

1. **台北指南擴至 10–15 篇總量**：由現有研究卡挑選可公開使用、官方入口可確認且分布不同地區的場館；候選不是已確認的熱門排行。每篇須有名稱／位置、適用公眾條件、目前租借入口或明確現場規則、來源與查核日期。費率、夜間、特定場次不足時個別標示待確認；不要發布只剩名稱與一排待確認的空指南。
2. **台北既有 61 座逐一盤點**：合格者發布指南；校園、會員限定、停用及開放不明者保留正確狀態。建立行政區／名稱查找、來源差異審核、失效入口追蹤及資訊回報流程，才繼續擴量。發布率以合格內容計，不承諾所有學校都可供外部人士使用。
3. **全台資料底稿可與第 1 階段並行**：官方開放資料初始匯入，保留來源 ID／網址／授權／擷取日，做名稱與座標去重、縣市區域核對、場馆與設施層級區分、網球分類與對外開放狀態查核。輸出各縣市候選數、重複／衝突／缺漏、可發布／待確認統計；不先宣稱全台完整或全部可租。
4. **全台公開目錄、指南與約球分批開放**：新北可作為優先查核候選，因已有 28 座底稿；其餘地區依已查核資料與實際需求決定。跨縣市約球另需評估當地球局供給、導覽、訂閱範圍及資料授權測試；不只改縣市選單。

## 官方來源與限制

- [運動部全國運動場館資訊（22849）](https://data.gov.tw/dataset/22849)：頁面標示每年更新、政府資料開放授權條款第 1 版。包含縣市、行政區、名稱、地址、座標、設施、開放與租借資訊，可作底稿，不能當即時空場或目前費率保證。
- [iPlay 公開資訊](https://iplay.sports.gov.tw/Home/Download)：提供場館資料下載，作初始來源之一。尚未在本次重新下载／計算全台網球總量或驗收 API 可用性，不估造筆數。
- [先前來源查核](../tennis-ecosystem/source-surveys-2026-08-11.md) 已記錄雙北官方資料缺漏、前端分類噪音與重複候選。這是 8 月歷史證據；全台新匯入仍需地方政府／營運單位交叉確認。
- 地方租借系統、場館與校方公告負責補充實際租借方式。採用自撰摘要與必要欄位，不直接搬入整頁文章、照片、個人姓名或非必要聯絡資料。

## 開發前需要處理的結構

- 現行指南解析限定台北，指南 slug allowlist 為三篇手動維護；擴至全目錄應從可發布資料產生映射並保留身份唯一性與登入意圖驗證。
- 現行 seed 的城市驗證限定雙北，且會依完整清單停用缺少的球場。全台初始資料應先置於獨立待審區，不能直接覆蓋 `data/courts.json` 或重跑發布 seed；不可讓新資料的缺漏停用現行球場。
- 以穩定球場 ID、來源 ID、別名與場館／設施層級對應，保留既有球局引用；「17 面」是同一場館的面數，不自動拆成 17 個重複地點。
- 分開資料查核狀態、指南發布狀態及約球服務範圍。未開放租借不等於不存在、免費開放或永久停用。
- 全台公開時採區域／視窗查詢及必要分頁、地圖點位聚合；不將全台資料包進首頁 JavaScript，不為擴張逕自調高既有大小預算。
- 定期查核分為自動連結存活與人工規則確認；HTTP 200 不代表內容仍正確。任何排程此階段僅規劃，未建立自動化。

## 本輪紀錄與下一步

本輪僅唯讀盤點程式、計算既有目錄數量、查閱官方資料頁並保存評估；沒有匯入、修改 runtime／DB、建立排程或部署。文件 `git diff --check` 驗證；未執行產品測試。

建議下一個核可範圍為「台北指南擴至 10–15 篇＋全台球場資料底稿及品質報告」。詳細匯入 schema、批次名單與公開範圍須在實作前列清楚；本次詢問不等於已核可全台開局。
