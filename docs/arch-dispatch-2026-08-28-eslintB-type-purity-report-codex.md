## 11. Codex五問

### 1. 如何證明兩條規則真的恢復？

effective config顯示一般 TS兩條皆 `[2]`；真 config lint綠。兩個有效 canary各自精準報
rule ID，byte-identical還原後回綠。generated檔則由獨立 override canary證明只留下兩筆
刻意記帳債。

### 2. 為何把 Promise union收成 unknown不會收窄 callback？

`unknown | Promise<unknown>` 在型別系統本來就等於 unknown；所有 sync value與 Promise都仍
可指派。三個 login callback contract同家族同步，auth API只移除 Promise inner union中的
null，Promise外殼與 runtime async行為不變。

### 3. 如何證明 assertion移除沒改 runtime或同步語意？

13檔 esbuild bytes/hash全等；notification只把 assertion換成 variable annotation；
requestGate interval、sessionStore Object.assign、truthy snapshot branch與 syncCommit呼叫都
逐 token保留。bundle raw/gzip亦淨0 B，完整unit/mock/local再交叉驗證。

### 4. generated override是否形成過寬盲區？

沒有。files恰一檔、rules恰一條；該檔 assertion與其他已恢復規則仍正常啟用。暫刪 override
只曝露兩筆指定 never union；generated檔本身零 diff且保留可重生性。
