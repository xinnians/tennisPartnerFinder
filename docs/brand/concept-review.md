# 第一輪 Logo 概念檢視

日期：2026-08-14

## 揪拍

影像模型多次把深綠與訊號黃做成暗色發光 mockup，即使 prompt 明確禁止仍未改善，因此這些 raster 結果判定不合格，不作為設計決策證據。可保留的只有「兩個相向括號在中央成為一個連結點」這個符號命題；已另做乾淨的 SVG 草圖驗證輪廓。

下一步測試：第一次看到是否聯想到「揪人打球」，還是攝影／開拍；24 px 時中央點是否仍清楚。

## 成局

生成稿成功把兩個半場、中央球點與完成狀態整合成緊湊方形，與產品「湊齊人、地、時」的承諾一致。風險是中央同心結構可能帶出瞄準、監控或定位感；SVG 草圖已減少同心圓層次。

下一步測試：不看副標時是否知道與球類有關；單色版是否仍像完整球場而不是 QR code。

## 球局

生成稿比現有 icon 增加球場與兩端連結，但大圓分割容易接近籃球、方向盤或放射標誌。現有 `public/icon.svg` 的辨識更乾淨，因此 SVG 鎖定稿保留 incumbent icon，只測試完整字標關係。

下一步測試：使用者是否把「球局」視為品牌，還是只當作產品類別；搜尋與口頭轉述是否能指向單一服務。

## 本輪結論

- 策略辨識度：揪拍最高。
- 產品承諾一致性：成局最高。
- 上線風險與轉換成本：球局最低。
- 尚不足以改名；先做 5–8 位台北球友的盲測，再把勝出方向進 Figma 精修。
